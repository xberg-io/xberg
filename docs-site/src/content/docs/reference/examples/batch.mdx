## Choose PDF layout for each input

Each input can override the batch's `use_layout_for_markdown` setting. An
omitted option inherits the batch setting. Swift takes the inputs as a JSON
array:

```swift
import Xberg

let inputs = """
[
  {"input":{"kind":"uri","uri":"invoice.pdf"},"use_layout_for_markdown":true},
  {"input":{"kind":"uri","uri":"notes.pdf"},"use_layout_for_markdown":false}
]
"""
let result = try await extractBatchWithInputOptionsJson(inputs, "{}")
```
