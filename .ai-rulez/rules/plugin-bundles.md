- Edit only `plugin/.ai-rulez/` (skills, commands, references, `config.plugins.toml`) and `plugin/README.md`. The
  per-runtime bundles under `plugin/`, the root marketplaces and all of root `skills/` are generated by
  `mise run plugin:generate` (`ai-rulez generate --plugin` + `scripts/sync_public_skills.py`); CI Lint fails on drift
  (`mise run plugin:verify`).
- The plugin version follows core through `mise run version:sync`; never set it by hand.
