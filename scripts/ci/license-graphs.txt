#
#   label|manifest|features|target
#
# `check-licenses.sh` audits each row with cargo-deny and `generate-notices.py` collects the
# same rows into the third-party notice bundle, so a graph added or changed here changes both
# the license gate and the notices it certifies. An empty features column means the crate's
# default features; an empty target column means every platform's target-specific dependencies
# are resolved, not just the host's.
